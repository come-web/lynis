## 自查工具要求（v10.2）

- 只使用 **2026 版 / v10.2**。其它版本导入新平台会失败。
- 无信创版、无 macOS 版，用 Windows 电脑安装。单机版，**不要装到服务器上**。
- 下载：百度网盘 `https://pan.baidu.com/s/1JzhTfuOqD1uqvJSBuhtWZw?pwd=cywa`，目录「2026.9.14等保自查」。下不了联系网安。
- 单位名称到天眼查、启信宝查询后**复制粘贴**。括号必须区分中文 `（）` 和英文 `()`。
- 网络数 = 系统数。
- 「是否组织开展关键信息基础设施保护工作？」选 **不适用**（5 家单位除外，这 5 家自知，不要问在不在名单内）。
- 「四、落实关键信息基础设施安全保护制度情况」选 **不适用**。
- 「五、落实网络安全重点措施情况」里，从「是否设计和建设本单位网络安全综合业务平台？」到「业务平台包含的其他业务模块及相关情况说明：」是态势感知平台。没有就选 **否**。
- 自查总结须单位主要领导签字、盖章，扫描后上传到工具。填完导出 zip，再发邮箱、上传平台。
- 自查总结必须使用分局下发的模板。Lynis 只提供技术备忘，不能当正式总结。

## Lynis 在本项工作中的位置

等保自查的正式材料来自 v10.2 工具和分局模板。对本仓库中的 **Linux / UNIX 定级对象主机**，可以用 Lynis 做三件事：

1. 按 GB/T 22239-2019 技术要求扫主机，输出 OK / GAP / 需确认。
2. 把 GAP 作为整改清单（防火墙、审计、恶意代码、完整性、时间同步等）。
3. 导出技术备忘，作为自查总结和工具填报的附件证据。**不能**代替签字盖章的自查总结，也**不能**当测评报告。

```sh
# 在定级对象主机上（建议 root）
./lynis audit system --profile dengbao.prf --quick --auditor "等保自查"

# 或使用包装脚本
sh extras/dengbao/run-selfcheck.sh

# 扫描结束后导出中文技术备忘
sh extras/dengbao/export-memo.sh
```

对照关系见 `control-map.md`。插件在扫描结束阶段输出「MLPS 2.0 technical controls」。

完整勾选清单见 `work-plan.md`，或运行 `sh extras/dengbao/print-work.sh`。
