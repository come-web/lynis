## 0. 先分清两套工具（最容易搞错）

通知里有两张工具截图，对应两件不同的事：

| | 现在要做：自查 | 前期做过：备案材料更新 |
| --- | --- | --- |
| 时间窗 | 2026-09-14 至 2026-10-31 | 2026-04-15 起 |
| 工具全名 | **2026 版等保自查工具** | **网络安全等级保护备案填报工具**（更新工具） |
| 版本识别 | 安装过程显示 **v10**，打开后显示 **v10.2** | **v1.1 或 v1.2** |
| 产出 | 自查 zip（导入 wy / 市级新平台） | 备案更新 zip（导入部级 / 市级平台） |
| 谁发起 | 公安自查，**和测评无关** | 按公安部 1001、1846 号文更新备案材料 |

判定：

```
要不要现在填「更新工具」？
  ├─ 已经用 v1.1 或 v1.2 导出过 zip  → 不要再填
  ├─ 系统是 2026-08-10 以后才备案     → 不要填更新工具
  └─ 以上都不是、且从未导出过更新 zip → 还要补做更新材料（与自查并行，工具不同）

要不要现在填「自查工具 v10.2」？
  ├─ 系统在 2026-09-14 之前已备案     → 必须填，不要说等测评后再自查
  └─ 系统在 2026-09-14 及以后才备案   → 本轮通知未要求此次自查
```

下载自查工具：百度网盘 `https://pan.baidu.com/s/1JzhTfuOqD1uqvJSBuhtWZw?pwd=cywa`  
进文件夹 **「2026.9.14等保自查」**。下不了联系网安。  
无信创版、无 macOS 版，用 **Windows 电脑**安装。单机版，**不要装到服务器上**。

## 4. 登录新平台核对接没接上备案

8 月 10 日市级平台已从「等保备案预约平台」升级为「网络安全等级保护管理系统」，**没有自动迁完所有备案**。

| 入口 | 数据来源 |
| --- | --- |
| 综合查询 | 前期更新工具 zip 推送后的数据 |
| 历史查询 | 旧平台「等保备案预约平台」的备案数据 |

综合查询比历史查询少系统时，先自查这三种原因：

1. 漏填备案信息
2. 填报信息错误，未推送
3. 更新工具里**定级对象编号重复**

新平台没有备案数据，视为未备案。

2026-09-01 起新系统备案：用新的专家评审意见模板和定级报告模板，先联系公安机关。专家评审必须线下，禁止套用签字。
