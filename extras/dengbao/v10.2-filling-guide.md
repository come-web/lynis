# v10.2 自查工具填报说明

只用于 **2026 版自查工具 v10.2**。  
不要用这份说明去填「网络安全等级保护备案填报工具」（更新工具）。

正式总结必须用**分局下发模板**。本页只固定通知里已经写死的选项，并给一份可打印底稿。

---

## 安装与识别

- 下载目录：百度网盘「2026.9.14等保自查」
- 安装过程显示 **v10**，打开后必须显示 **v10.2**
- Windows 单机。不要装到服务器，没有 macOS / 信创版
- 填完导出 zip，再发邮箱、上传平台。其它版本导入新平台会失败

---

## 通知已经写死的选项

| 位置 | 怎么填 |
| --- | --- |
| 单位名称 | 到天眼查 / 启信宝查询后**复制粘贴**，不要手打。括号分清 `（）` 和 `()` |
| 网络数 | **等于系统数**（有几个已备案系统就填几） |
| 是否组织开展关键信息基础设施保护工作？ | **不适用**（5 家单位除外；这 5 家自知，不要问在不在名单内） |
| 四、落实关键信息基础设施安全保护制度情况 | **不适用** |
| 五、落实网络安全重点措施情况：从「是否设计和建设本单位网络安全综合业务平台？」到「业务平台包含的其他业务模块及相关情况说明：」 | 这是**态势感知 / 综合业务平台**。没有就选 **否** |
| 已备案系统 | **全部**填进工具，2026-09-14 前备案的一个不能漏 |
| 自查总结 | 分局模板 → 主要领导签字盖章 → 扫描上传工具 |

其余技术字段按系统真实情况填。Linux 主机可用 `export-memo.sh` 的 GAP / 需确认项对照，但不能把备忘直接当总结。
